# Практическая работа №3

Дневник на Vue 3 и Pinia. Компоненты написаны с Composition API.

Можно добавлять, изменять и удалять посты, показывать комментарии,
добавлять и удалять их. Кнопка «Закрыть» отменяет редактирование поста.

## Запуск

Нужен Node.js 22.12 или новее.

```bash
npm install
npm run dev
```

Для сборки: `npm run build`.

Посты и комментарии хранятся в Pinia. После обновления страницы
загружаются начальные примеры.

Ветка `main` — исходники, `gh-pages` — сборка для GitHub Pages.
